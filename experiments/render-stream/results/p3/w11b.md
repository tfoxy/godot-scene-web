# W11b: the capture emits render-stream/11 (2026-10-27)

Under `GRC_STREAM_VERSION=11` the capture now writes and serves render-stream/11
([protocol/render-stream-11.md](../../protocol/render-stream-11.md)):

- meshes that animate become **dynamic**, and their surface bodies travel by mesh id inside the
  transaction (`mesh_u8`);
- each stream's resource records are inline(T) \ inline(B), the pruned carried set;
- WB's **stable `content_version`** and **patched `unsupported`** are in.

Every older version and the default environment are unchanged. On STS2 combat the warm message is
**78,219 B raw and 12,467 B with base-prefix zstd-3**. /10 sends about 256,900 B for the same
frame. WB predicted 79,968 and 12,471. The capture's frame callback fell from 8.1 ms to 5.7 ms a
frame.

## Decisions

These are recorded in render-stream-11.md, "As built (W11b): decisions". Only the first one
changes what a validator sees.

1. **A stable `content_version` is a digest of the command list**, not "the published version
   restored". At /11 each item's `content_version` is the first 53 bits of the SHA-256 of its
   encoded commands (JSON, then `cmd_f32` and `cmd_i32` from offset 0).
   - **Why not the sketch.** The sketch's rule fails `content-version-stable` whenever a
     connection's base is older than the last snapshot: a list that goes X, Y, X gets a new version
     over X's commands. That happens at window 1 under phase lock, at window 2, after a stall and
     at a resync. A digest holds for any (B, T) and keeps no history.
   - **Cost.** The digest is recomputed only for items that recorded since the last snapshot.
   - **Collision.** A collision between two lists of one item is a 2^-53 event, and would show as
     stale commands.
   - **Scope.** It applies to every connection of a /11 host. At /10, equal versions over equal
     lists are what /1 always meant.
2. **Classification.**
   - A content change is a hook call that changes surface bytes. Region updates are compared by
     the hook's own payload hash, so there is no shadow memcmp.
   - Changes count once per host frame, and never in the mesh's build frame.
   - `auto` promotes a mesh at its second change frame within K (f2 − f1 ≤ K). The decision is
     taken at the snapshot, and needs an `ok`, non-empty mesh within `max_bytes`, which is checked
     at promotion only.
   - A dynamic mesh is never demoted. Empty at a snapshot, it encodes like a static mesh.
3. **The hook still hashes dynamic surfaces.** The hook log (`dyn-wire`), change detection and a
   /10 viewer of a /11 host all need the GRM1 hash. The snapshot keeps each dynamic surface's GRM1
   payload beside its body. Skipping the hash is a host-cost follow-up (P3-CAP's area).
4. **Records.**
   - Live connections, like file sinks, send `records_before(B, T)`, with B the last snapshot
     sent, a resync included.
   - The hub memoizes the record list per (B, T) pair, and each record's encode per hash, once per
     frame callback. A /11 connection takes no `CarriedIndex` slot.
   - P3-SP's sharing holds: lockstep /11 viewers share transactions and records, and each gets the
     bytes it would get alone (`rs_live_test`).
5. **`payload_bytes`** of a dynamic surface is the body's length, written by the /11 encoder.
6. **Three /11-only sabotage kinds** go into the session's enum, accepted by the TypeScript
   validator and rs-core at /11 only:
   - `cv-churn`: the mirror's own counter;
   - `stale-dynamic`: one dynamic mesh's serial frozen from the sabotage frame;
   - `keep-carried`: /10's lifelong set, in file sinks and live connections.
7. **Conditional hooks.** /11 installs /10's conditional hooks: both back-buffer setters, and
   P3-CK's `draw` (rebased onto `f3337f03`).

## Memory-worthy

- A stable `content_version` must be a function of the command list, or a base older than the
  last snapshot breaks `content-version-stable` (X, Y, X).
- `fixtures/capture-scale` redraws nothing by default; WB's redundant-item effect needs
  `RS_SCALE_REDRAWS`.
- The golden-11 control hello's `credit_stage` is `submitted`: a hub test acking `applied` gets
  no credit back and sends one transaction.
- `receiver.gd` refuses `GRSB` before the capi sees it: a native /11 file replay is `bad-magic`
  until W11d.
- On STS2, WB's predictions held within 1 %: combat lean 78,219 measured against 78,729, prefix
  12,467 against 12,388 on the same scene of `cg4-a10-2`.
